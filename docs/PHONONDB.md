# NIMS PhononDB ingestion

GeoForm can verify and export a calculation directly from the NIMS MDR archive indexed by PhononDB. The public index contains 10,034 records. A record represents a particular calculation for a Materials Project phase. GeoForm assigns a durable `nims-mdr:<record-id>` identifier and retains the source formula, Materials Project ID, and verified space group. Mineral names remain unassigned. Multiple phases may have the same composition.

- [NIMS MDR phonon calculation database, Atsushi Togo](https://doi.org/10.48505/nims.4197)
- [Pinned official index](https://github.com/atztogo/phonondb/blob/8cabbe0aee3dde48a19f1235864b0d3ab5cb9330/mdr/phonondb/README.md)
- [Phonopy YAML and compression documentation](https://phonopy.github.io/phonopy/phonopy-yaml.html)
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## Replay the first batch

Install the optional ingestion dependencies and use the same interpreter for all steps. Set BLAS and OpenMP to one thread when using several verification workers. The receipt records versions and source-code hashes.

```sh
python -m pip install -e '.[phonondb]'
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1

revision=8cabbe0aee3dde48a19f1235864b0d3ab5cb9330
mkdir -p work
curl -fL "https://raw.githubusercontent.com/atztogo/phonondb/$revision/mdr/phonondb/README.md" -o work/index.md
geoform-phonondb index work/index.md "$revision" work/index.json --sha256 15e71b6511f5b3b071b7e28cda9b5b987575bd47956bb96c5ccd8fb58a6f475f
geoform-phonondb fetch work/index.json work/fetch.json --cache work/cache \
  --ids benchmarks/phonondb_first_batch_ids.json --pins benchmarks/phonondb_first_batch_pins.json \
  --workers 8 --timeout 90
geoform-phonondb rights work/index.json work/rights.json \
  --ids benchmarks/phonondb_rights_sample_ids.json --workers 8 --timeout 90
geoform-phonondb verify work/index.json work/verified --cache work/cache \
  --ids benchmarks/phonondb_first_batch_ids.json --rights work/rights.json --workers 6
```

`fetch` without `--pins` pins the first successful HTTPS response by SHA-256 and byte length. These are replay pins generated by GeoForm. For an existing pin, modified or missing bytes are reported separately. A missing archive can be re-fetched against the existing pin. If a corrupt local cache copy must be replaced, remove the ZIP and keep its pin. Use one writer per record or shard concurrent fetches into disjoint selections. License checking reads each selected MDR record's dataset metadata. Without a successful individual check the catalog explicitly reports collection-level evidence or the unconfirmed status.

`verify` is offline. Its `records/` directory holds per-record successes and failures. It reuses a prior successful result only after checking source archive bytes, product hash, code hashes and settings. Each aggregate covers only that invocation's selection. `catalog.json` indexes passing calculations and `results/` contains corresponding GeoForm result JSON. `receipts.json` includes every selected row, timings, software versions and hashes. A nonzero exit indicates at least one failed record. Successful records remain available. For subsequent waves use an ID selection or `--start` and `--limit` on the same pinned index. To aggregate batches, run `verify` over their combined selection in the same output directory. Verified records can be reused. Collection rights and record-level rights are separate fields.

## Verification and scope

- Verify the archive digest, read one bounded XZ YAML member without extraction, and pin the compressed member and decoded YAML. Source PNGs and VASP settings are outside the ingestion path.
- Check lengths, masses and IFC units. Verify finite ordered structures, supercell transformation, element counts, space group and site-by-site agreement between stored and rebuilt cells. Recompute the space group with spglib at the recorded tolerance.
- Reconstruct compact IFCs from embedded Type-I displacement/force snapshots via Phonopy finite differences and its symfc projector. If embedded IFCs are available, load them directly without projection. GeoForm checks the adapter's shortest-image reconstruction, transpose reciprocity, acoustic sum rule and nonzero IFCs. GeoForm and Phonopy share the force inputs. This comparison checks postprocessing and does not independently rerun VASP.
- Compare 16 complex dynamical matrices and every signed frequency on the fixed probe set, 48-point generic path and full shifted mesh. The default `6 × 6 × 6` mesh yields 280 q evaluations including shared endpoints. Compare total Gaussian DOS and all reported thermal temperatures against Phonopy for cases with positive mesh modes and no detected instability. DOS uses 0.1 THz smearing and integrates to three states per primitive atom within tolerance.
- Preserve negative frequencies. A negative signed mode can be classified as Γ roundoff only at exact Γ or a reciprocal image, within 0.001 THz in both solvers, and with over 99.9% mass-weighted translation overlap in both. Preserve the raw minimum and record how many sampled modes met this rule. Withhold DOS and equilibrium thermal outputs for every remaining negative mode or zero on the shifted mesh.
- Alias only byte-identical decoded calculation payloads. A separate standardized metric and motif fingerprint flags candidate duplicate structures for review. A matching fingerprint does not establish structural identity and keeps distinct force data separate.
- The sample grid does not establish dynamical stability throughout the Brillouin zone. Results use bare harmonic IFCs without polar LO–TO correction. DOS and constant-volume thermal properties are finite-mesh calculations. The phase catalog is separate from the existing nine-case engine catalog and the hosted Mineral Lab.

The current import envelope supports up to 64 primitive atoms and 650 supercell atoms, with bounded archive/YAML sizes. Large cells, unsupported displacement representations and irreconcilable order or space-group differences remain quarantine cases. Confirm individual record rights before a wider release where record-level evidence is required. Curate natural mineral links against independent structural evidence before counting mineral profiles.

## First-batch result

The initial selection contains 350 archive records. It combines the first 20 index rows, every 80th index row starting at row zero, and all rows matching 34 specified formulas of mineral or benchmark interest. Overlaps count once. This deliberately mixed sample is unsuitable for estimating collection-wide stability.

| Measure | Observed |
| --- | ---: |
| Official index rows | 10,034 |
| Archives downloaded and checksum-pinned | 350 |
| Independently cross-checked and exported calculations | 322 |
| Distinct reduced compositions / space-group numbers | 152 / 87 |
| DOS and thermal curves on sampled-positive phases | 142 |
| Signed dispersion only due to sampled imaginary modes | 180 |
| Quarantined at the primitive-cell budget | 28 |
| Byte-identical payload groups / matching structural fingerprints | 0 / 0 |
| Assigned natural mineral identities | 0 |

Archive acquisition transferred 67,596,959 unique archive bytes in about 10 minutes 35 seconds, including initial access latency and overlapping fetch shards. Eight verification workers processed the full selection in 49.538 seconds from local archives, about 7.1 attempts or 6.5 verified calculations per second. The largest matrix difference was 8.68 × 10⁻⁸ (eV/Å²)/amu and the largest signed-frequency difference was 1.13 × 10⁻⁴ THz. All 322 passing packages used embedded Type-I forces. A separate test loaded 13 representative packages directly through `phonopy.load` with NAC disabled and reproduced the ingestion route at all 16 matrix probe points.

The 28 quarantined packages had 68–180 primitive atoms. Every package within the first batch's resource envelope passed the verification gates. All 13 checked record pages confirmed CC BY 4.0. The other 309 accepted records carry collection-level rights evidence. These 322 calculations are a separate catalog with 58 distinct SiO₂ calculations and 61 ZnS calculations among its entries. Some of the source phases overlap the pre-existing nine-structure benchmark catalog. The reported count has no cross-catalog deduplication.

## Composition breadth release

The second selection prioritizes previously unattempted reduced compositions.
It considers explicit profile compositions from GeoForm's browse index first,
then covers other compositions, with a seeded SHA-256 ordering for
reproducibility. Composition overlap serves as a selection signal. Mineral
identity remains unassigned. The frozen 750-ID plan and the 228-ID release
snapshot are recorded separately. The snapshot covers the archives retrieved
and checked at the release cutoff.

| Measure | Additional | Combined |
| --- | ---: | ---: |
| Pinned archive attempts | 228 | 578 |
| Verified calculations | 220 | 542 |
| DOS and constant-volume thermal curves | 123 | 265 |
| Signed dispersion only | 97 | 277 |
| Primitive-cell budget exclusions | 8 | 36 |

The 220 new calculations span 220 distinct reduced compositions. The combined
catalog has 359 compositions after integer stoichiometries are reduced by their
greatest common divisor, and 105 space-group numbers. The comparison uses the
same force inputs, 16 matrix probes, generic path, shifted mesh and omitted
nonanalytic correction described above.

After preparing the pinned source index as above, replay the released selection
with these commands.

```sh
geoform-phonondb fetch work/index.json work/breadth-fetch.json --cache work/cache \
  --ids benchmarks/phonondb_breadth_ids.json --pins benchmarks/phonondb_breadth_pins.json \
  --workers 8 --timeout 90
python -c 'import json,pathlib; p=pathlib.Path; files=("first_batch","breadth"); ids=sorted({i for f in files for i in json.loads(p(f"benchmarks/phonondb_{f}_ids.json").read_text())}); p("work/combined-ids.json").write_text(json.dumps(ids))'
geoform-phonondb verify work/index.json work/verified --cache work/cache \
  --ids work/combined-ids.json --rights work/rights.json --workers 7
```

The combined replay expects both batches' pinned archives in the same cache and
can exit nonzero for the documented resource exclusions. The verified catalog,
per-record receipts and payloads remain available. Source-index discovery and
verified result counts are reported separately.
